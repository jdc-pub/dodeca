This page verifies that `.adoc` files are parsed and rendered correctly.

== Introduction

AsciiDoc is a lightweight markup language with rich support for technical
documentation. Dodeca processes `.adoc` files via the `cell-asciidoc` cell,
which uses https://github.com/nlopes/acdc[acdc-parser] for parsing and
`acdc-converters-html` for rendering.
